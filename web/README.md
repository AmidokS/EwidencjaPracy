# Учёт работы — веб-приложение (PWA) для iPhone и Android

Устанавливается по ссылке: Safari → «Поделиться» → «На экран „Домой“».
Работает без интернета, все данные хранятся только на телефоне.

## Как выложить в интернет (бесплатно, один раз)

Вариант 1 — Netlify (проще всего):
1. Зарегистрируйся на https://app.netlify.com (бесплатно).
2. Открой https://app.netlify.com/drop и перетащи туда папку `web` целиком.
3. Получишь ссылку вида `https://что-то.netlify.app` — её и рассылай.
   В настройках сайта (Site configuration → Change site name) можно задать имя,
   например `uchet-raboty.netlify.app`.
4. Обновление: Deploys → перетащить папку `web` ещё раз. Ссылка останется той же.

Вариант 2 — GitHub Pages:
1. Зарегистрируйся на https://github.com, создай публичный репозиторий `uchet`.
2. «Add file → Upload files» → перетащи **содержимое** папки `web`.
3. Settings → Pages → Branch: `main`, папка `/ (root)` → Save.
4. Через минуту ссылка: `https://твой-логин.github.io/uchet/`.

## Важно для пользователей
- Ставить на iPhone нужно именно через **Safari**.
- Если удалить иконку с экрана — записи удалятся. Раз в месяц: Настройки → «Копия».
- При обновлении приложения новая версия подтягивается при следующем открытии с интернетом.
